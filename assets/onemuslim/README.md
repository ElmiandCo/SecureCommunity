# OneMuslim Islamic UI Assets

Reusable decorative assets for the OneMuslim visual system. SVG is used as the source format so the assets stay crisp at every resolution and can inherit theme treatment without raster artifacts.

## Theme assets
- `pattern-light.svg` — cream geometric background
- `pattern-dark.svg` — deep green geometric background
- `mosque-light.svg` — subtle light mosque silhouette
- `mosque-dark.svg` — subtle dark-theme mosque silhouette

## Accents
- `crescent-gold.svg`
- `divider-gold.svg`
- `divider-green.svg`
- `arch-gold.svg`
- `corner-ornament.svg`

Use these as background layers and decorative elements rather than replacing core content. Keep opacity restrained so the social UI remains primary.

Brand palette: deep green `#1F5B49`, gold `#C89D3C`, cream `#FBF8F1`, dark green `#0D3028`.
