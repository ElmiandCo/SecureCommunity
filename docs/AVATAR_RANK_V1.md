# One Muslim Avatar + Rank V1

## Rank
- Every new member starts at **100 Rank points**.
- Profile completion awards points once per category.
- Avatar save awards +25 points.
- First post awards +10 points in the demo client.
- At **1,000 Rank points**, avatar customization controls unlock.

## Initial male avatars
Three supplied male avatar images are stored under `assets/avatar/male/` as `male-1`, `male-2`, and `male-3`. A female option is reserved as Coming Soon.

## Mask colors
V1 includes generated mask-color variants for each male base: white, black, teal, gold, royal blue, emerald, crimson, and purple. These are convenience assets generated from the supplied images; replace them with designer-approved source layers when available.

## Future unlocks
The UI reserves controls for headwear (hat / Islamic scarf), shirt color, background color, and eye-glow color. Those controls remain locked until Rank 1,000.

## Persistence
The selected avatar configuration is stored as JSON in the profile `avatar` field. The app can render the saved avatar as a small circular identity image in the header and other authenticated surfaces.
